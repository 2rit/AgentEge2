Personal_AI_Agent.mcaddon

แพ็กเกจหุ่นยนต์คู่หู AI สำหรับโหมดเอาชีวิตรอด (Survival) พร้อมโมเดล 3D 24 ชิ้นกระดูก, อนิเมชันสมูท 15 ท่าทาง, สมองกลจัดลำดับความสำคัญ 5 ชั้น, ระบบพลังงาน/แท่นชาร์จ, ชิปอัปเกรด 7 สาย และรีโมทเมนูภาษาไทย

📲 วิธีติดตั้งเข้าเกม (ไฟล์เดียวจบ)

  1. กดรับไฟล์ Personal_AI_Agent.mcaddon แล้วแตะเปิดไฟล์ด้วยแอป Minecraft
  2. ตัวเกมจะนำเข้าทั้ง Personal AI Agent [BP] และ Personal AI Agent [RP] ให้อัตโนมัติ
  3. ไปที่ตั้งค่าโลก (Create New World หรือ Edit World) → หมวด Behavior Packs → กด Activate (Resource Pack จะเปิดพ่วงให้อัตโนมัติ ไม่ต้องเปิดโหมดทดลอง)

🛠️ วิธีสร้างและสั่งงานหุ่นยนต์ใน Survival

  1. คราฟต์ AI Core + Standard Battery Cell ที่โต๊ะคราฟต์
  2. คราฟต์ AI Robot Assembly Unit แล้วกดวางลงพื้น หุ่นยนต์จะเกิดพร้อมมอบ Agent Remote Control ให้ทันที
  3. ถือรีโมทแตะค้างหน้าจอ / คลิกขวา เพื่อเปิดเมนูสั่งงาน FOLLOW / ASSIST / STAY / WORK / DEFEND / CHARGE
  4. ย่อตัว (Sneak) + ถือรีโมทแตะแท่นชาร์จ หรือ Chest เพื่อผูกจุดชาร์จไฟและกล่องฝากของอัตโนมัติ
