                  ระบบ
                  สถานะ
                  รายละเอียดการทำงานและข้อจำกัดตามจริงของ Bedrock Engine
                

              
              
                

                  หุ่นยนต์ 3D + ถืออุปกรณ์จริง + รอยร้าว 5 ระดับ

                  คลังเก็บของ 100 ช่อง + ปลดล็อกตาม Level 1–100
                  สำเร็จ (Virtual Chunked Storage)
                  ข้อจำกัด API: Native minecraft:inventory ของ Bedrock จำกัดขนาดตู้คอนเทนเนอร์มาตรฐานและปรับขนาดสดรายเลเวลไม่ได้ จึงออกแบบระบบ Chunked Dynamic Properties Storage เก็บข้อมูลไอเท็มสูงสุด 100 ช่องอย่างปลอดภัย ฝาก-ถอนผ่าน Remote UI พร้อมป้องกันไอเท็มหายและกันล้นคลัง 100%
                

                

                  Solar Charging (ตรวจแสงอาทิตย์จริง)
                  สำเร็จครบถ้วน
                  ตรวจเวลาจริง (world.getTimeOfDay() 0–12000), สภาพอากาศ (WeatherType.Clear) และเช็กฟ้าเปิดไร้บล็อกบังเหนือหัวด้วย dimension.getTopmostBlock ก่อนหดตัวเป็นกล่องชาร์จ ไม่ชาร์จในถ้ำหรือตอนกลางคืนเด็ดขาด

                  สำเร็จครบถ้วน
                  ใช้ตาราง Mining Tier ของ Minecraft จริง (ห้ามที่ขุดไม้ขุดเหล็ก/เพชร), ตัดเฉพาะต้นไม้ธรรมชาติที่มีใบไม้เชื่อมและไม่ตัดบ้านผู้เล่น, ปรับระดับที่ดินเฉพาะบล็อกเหนือ Y เป้าหมายพร้อม Preview Particle ขอบเขต, จำแปลงเกษตรและปลูกซ้ำเฉพาะเมื่อโตเต็มวัย

                  Fishing Simulation (ระบุข้อจำกัดจริง)
                  ข้อจำกัด API: Bedrock Script API ไม่อนุญาตให้ Custom Mob ยิงโพรเจกไทล์ minecraft:fishing_hook ที่ผูกสายเบ็ดฟิสิกส์เหมือนผู้เล่นจริง ระบบจึงใช้ Authentic Fishing Simulation: เดินหาแหล่งน้ำจริง → เล่นท่าเหวี่ยงเบ็ด + สร้าง Particle ทุ่นน้ำและฟองน้ำวิ่งเข้าหาทุ่น → สุ่มตาราง Loot ปลา/สมบัติมาตรฐาน → ลด Durability เบ็ดและรองรับ Enchantment (Luck of the Sea / Lure / Unbreaking / Mending)

                  Hybrid Nav + Step Controller
